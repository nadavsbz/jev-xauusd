| `UseSecureProfit`, `LockActivateProfit`, `SecureNetProfit`, `LockConfirmSeconds` | נעילת רווח נטו קטן אחרי שהפוזיציה מרוויחה מספיק ומחזיקה את הרווח כמה שניות |
| `UsePhantomChain`, `SLTriggerDistance` | הסטופ האמיתי נשאר וירטואלי ונסגר בשוק. סטופ ביטחון אמיתי מונח רחוק יותר אצל הברוקר |
| `UseFixedChainSpacing`, `ChainSpacingPoints`, `UsePaceKeeper` | פתיחה נוספת מעל, כשהפוזיציה החדשה בטריילינג |

| `UsePrediction`, `PredConfidenceMin`, `PredDcaAdjustPct`, `BlockChainOnBearPred` | רגרסיה ליניארית על סגירות דקה, עם R² כ"ביטחון". בתחזית דובית צעד ה-DCA רחב יותר, ואין שרשרת מעל |
| `UseCrashDetection` ו-8 פרמטרים | ציון קריסה על נרות דקה: מהירות, נרות אדומים ברצף, גוף נר גדול וספרד רחב. בציון 2 ומעלה אין כניסות עד שמתייצב |
| `UseMarketContext` ו-7 פרמטרים | אין כניסות כש-D1, H4 ו-H1 כולם מתחת ל-EMA, כשהמחיר רחוק מאוד מתחת ל-EMA היומי, ביום חריג, או אחרי ירידה של 3% בהון |
| `UseLogCompounding` | הגדלת לוט לוגריתמית מהרווח, עד המכפיל המקסימלי |
| `UseMarginProtection`, `UseRiskLimit`, `MaxDrawdownPercent` | בדיקת מרג'ין לפני פתיחה, סגירת חירום, וסגירת הפוזיציה הגרועה אם היא עמוקה מדי |
| `Resistent`, תצוגה | מתקבלים ולא בשימוש |
