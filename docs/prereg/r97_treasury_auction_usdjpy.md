# סבב 97 - רישום מראש (17.11.2026, לפני הורדת נתונים וקוד): תוצאת מכרז אג"ח ארוך → USDJPY
מקור: GPT ‏t280, רעיון 1 (דירוג ראשון, 14%). הרשימה נבנתה מראש עם תקרת העלות של המשתמש.

**ההשערה:** מכרז חלש מחייב תשואה גבוהה יותר. התשואות עולות, והדולר מתחזק מול הין עד סוף המסחר בניו-יורק. מכרז חזק פועל בכיוון ההפוך.

**האירועים:**
- מכרזי Note ו-Bond רגילים, כולל reopenings, שהטווח המקורי שלהם 7, ‏10, ‏20 או 30 שנה. בלי TIPS ובלי FRN.
- **המקור:** ‏Fiscal Data API של משרד האוצר האמריקאי, ‏`auctions_query`. ציבורי ובלי הרשמה.
- **שמירה:** תמונת מצב ב-`data/raw/auctions/`.
- **ההיסטוריה:** מורידים מ-2015, כדי שיהיו 12 מכרזים קודמים כבר ב-2018.

**האות, לכל מכרז:**
- ‏btc = ‏bid-to-cover.
- ‏ind = ‏indirect accepted / total accepted.
- ההשוואה מול 12 המכרזים הקודמים **של אותו טווח מקורי** בלבד, עם `np.quantile` ליניארי.
- **חלש:** ‏btc < ‏q20 **וגם** ‏ind < ‏q20 → לונג USDJPY.
- **חזק:** ‏btc > ‏q80 **וגם** ‏ind > ‏q80 → שורט USDJPY.
- **ביצוע:**
  - כניסה בפתיחת בר ה-M5 של 13:05 ET. התוצאות מתפרסמות ב-13:00 ET.
  - יציאה בפתיחת בר 15:55 ET.
  - בשרת: ET+7, או ET+6 בשבועות אי-התאמה (`scan2.mismatch`).
- **שני מכרזים באותו יום:** בכיוון זהה, עסקה אחת. בכיוונים מנוגדים, אין עסקה.

**לא סוחרים:**
