# סבב 59 - רישום מראש (15.11.2026, לפני קוד): אפקט תחילת החודש (Turn of Month) ב-S&P 500
מקור: Ariel 1987; Lakonishok & Smidt 1988; McConnell & Xu 2008 (ימים -1 עד +3 סביב תחילת החודש). [ASSUMED מהזיכרון]
- נתונים: data/derived/scan/h1/US500Cash.csv (RF, מ-12/2017). סגירה יומית = סגירת נר 22 בשרת (16:00 ET); אם חסר - הנר האחרון שלפני 23.
- ימי מסחר = ימים עם נר 22. יום -1 = יום המסחר האחרון בחודש; +1..+3 = שלושת ימי המסחר הראשונים בחודש הבא.
- כלל: לונג בסגירת יום -2, יציאה בסגירת יום +3. בכל חודש. אין סינון ואין שורט.
- עלות: tcost(US500Cash) לכל צד; swap לונג ‎-8.6% לשנה לפי ימים קלנדריים.
- תשואה יומית מכוילת ל-10% תנודתיות (scale).
- dev 2018-2022; holdout 2023-2026.10 פעם אחת רק אם dev עובר.
- סף dev: שארפ >=0.8, לפחות 4/5 שנים חיוביות, מתאם <=0.3 עם C1 ו-I2. דיווח גם ממוצע נטו לאירוע ו-t.
- תיאור בלבד (לא בוחרים): ממוצע תשואה יומית בימי החלון מול שאר הימים.
- ציפייה לפני: כ-20% (אפקט ידוע מאוד, ייתכן שנחלש; 2018-2022 כולל 2020 ו-2022).
