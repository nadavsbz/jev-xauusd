- **V2, יציאה בזמן:** בנוסף ליציאה הרגילה, יוצאים אחרי n נרות.
- **ככלל, בכל הגרסאות:** אחרי יציאה, כניסה חוזרת רק בפריצה חדשה של n נרות.
