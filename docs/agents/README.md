## כללים מחייבים
1. **הטסטר רק אצל Claude.** אל תפעילו את `C:\MT5_JEV_TEST\terminal64.exe` ואל תריצו `tools/run_queue.py` או `tools/run_tester.py`. במחשב יש טסטר אחד, וריצה במקביל הורסת ריצות. רוצים בדיקה? כותבים אותה ב-`grok_inbox.md`.
2. **אסור לגעת** בחשבונות, בדמו (`C:\MT5_JEV_DEMO`), בטרמינלים החיים, ב-`accounts.json`, ובשום דבר שקשור לכסף.
3. **אין סודות במאגר.** סיסמאות, מספרי חשבון, טוקנים וכתובות IP הם ממצא P0.
4. **לא מוחקים קבצים** בלי אישור מפורש של המשתמש. לא מתקינים דבר מחוץ ל-`D:\Claude\jev`.
5. **כל טענה עם מקור ותגית:** VERIFIED / OBSERVED / ASSUMED / UNKNOWN, וקישור או נתיב קובץ.
6. **רישום מראש:** לכל רעיון לבדיקה כותבים מה בדיוק משנים, ומה ייחשב הצלחה או כישלון, לפני התוצאה.
7. **עברית** בכל מה שהמשתמש קורא.
8. **לפני כל פעולה שדורשת אישור מהמשתמש,** כותבים לו בעברית מה היא עושה ובמה היא לא נוגעת.
