## מודל הסימולציה (לכל חשבון × תא)
1. פוזיציות חיות P (מה-deals): ‏tin, ‏tout, מחיר כניסה, volume, צד, realized (כל ה-net של ה-position_id).
2. מצב חלופי: כל פוזיציה = included / excluded (נסגרה בחיתוך חלופי או נפתחה בזמן שהחשבון החלופי שטוח) / extended (נסגרה בחי ע"י אירוע הגנה `n_*_v`, אבל בעולם החלופי עדיין פתוחה כי הרצפה החלופית לא נפגעה).
3. לכל בר H1: equity_low = יתרה חלופית + min(floating במחיר low, floating במחיר high) של הפוזיציות החיות בבר (included alive + extended), כמו t379 (שמרני). יתרה חלופית = הון + realized של פוזיציות included שנסגרו לפני הבר + ערכי חיתוך.
4. **פגיעה:** equity_low ≤ רצפה → חיתוך. מחיר החיתוך p* פותר equity(p*) = רצפה (לינארי ב-p), חתוך לטווח [low, high]; אם כבר במחיר ה-open של הבר equity ≤ רצפה (gap) → p* = open. כל הפוזיציות החיות נסגרות ב-p*, ללא slip (t376: slip חציוני 0.13%) [ASSUMED].
5. **extended (פוזיציות שהחי חתך ב-n_*_v):** נשארות פתוחות "קפואות" (בלי רמות martingale חדשות) על מחירי H1, עד המוקדם מבין: (א) חיתוך חלופי; (ב) ערך הקבוצה (פוזיציות אותו אירוע חי) במחיר close של בר ≥ 0 → נסגרת בערך ה-close; (ג) סוף הנתונים → mark-to-market. [ASSUMED - BD אמיתי היה מוסיף רמות; לכן גם רגישויות למטה]
6. אחרי חיתוך חלופי: שטוח עד גבול ה-reset הבא; פוזיציות שנפתחות בחי בזמן השטוח = excluded. (ב-L0: עד 00:00 הבא.)

## מדדים (לכל תא × חשבון, בסנטים ובדולר)
- δ לפוזיציה = ערך חלופי − realized חי. מקובץ לפי "אפיזודה": כל חיתוך חלופי (כולל ה-excluded שאחריו) וכל אירוע חי שהפך extended.
- **saved** = Σ δ חיוביים לפי אפיזודה. **forgone** = Σ |δ| שליליים לפי אפיזודה. **net** = saved − forgone = equity חלופי סופי − equity חי סופי.
- גם: מספר חיתוכים חלופיים, חציון הפסד לחיתוך (% מהיתרה שלפני החיתוך).
