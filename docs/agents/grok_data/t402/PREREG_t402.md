- סחר = זוג in/out לפי סדר באותו צד. hold = ts_out−ts_in. מקבילות = מס' סחרים פתוחים בו-זמנית.
- ‏DD: על equity בסגירות סחר (closed-trade). הצף בתוך הסחר UNKNOWN (אין מחירי ביניים) — מסומן.
- top-10 ימים: חלק הרווח הנטו (לכל התקופה) מ-10 הימים הטובים ביותר.
- נקודות לסחר: (exit−entry)×כיוון. ‏stress: הורדת 1.0 נקודה נוספת לסחר (round-trip), בשקלול vol.
- ‏live-equivalent: תשואות ×0.5 (TargetVol 0.075) [ASSUMED ליניארי].
