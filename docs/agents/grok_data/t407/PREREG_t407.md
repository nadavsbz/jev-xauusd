## 6. שלב 3 — שער fidelity (holdout 30%, נפתח פעם אחת)
- **התאמה:** כניסת מקור "מוסברת" אם יש אות של הכלל באותו סמל ובאותו כיוון:

- **סף מעבר (כל התנאים):**
  1. **recall** ≥60% מכניסות המקור ב-holdout (כיוון + שעה).
  2. **precision** (שיעור האותות שתואמים לכניסת מקור) ≥3× הדיוק של baseline אקראי.

  3. **מספר אותות** ב-holdout ≤3× מספר כניסות המקור. זה חוסם "לירות תמיד".
  4. **הכיוון** תואם ≥80% מהכניסות המוסברות.
