## Pass rule (frozen)

The decode gate is **per symbol**, because the random test and the cost cap are per symbol.

A symbol **passes** only if **both**:

1. **Timing** beats same-side random-entry at **one-sided p < 0.05** on the official statistic below, for that symbol.
2. **Concentration:** that symbol’s recorded EUR profit **survives dropping its own 10 best close-days**: remaining total EUR profit **> 0** and remaining trade-level PF **≥ 1.0**.

A **combined** (BTC+ETH) concentration and a combined timing test are reported as diagnostics, and cannot alone declare a pass.

**Inference** runs **only if BTC passes**. ETH fails the RoboForex **2 bp/side cash cap** (3.20 bp/side, VERIFIED t207), so no ETH rule is deployable even if ETH’s timing p is small. If BTC fails, the verdict is **FAIL** for the deployable (BTC) gate; say so clearly; **do not** infer.

If BTC passes and an inferred template also passes g1–g5 (g2b included) and the high-return size brief, only then consider MQL5. No retune after P&L.

## Official timing test (separate BTC and ETH)

**Real bp (primary):** TSV **fill prices** minus the RF cash and RF swap above, nights from the trade’s own UTC timestamps. Official statistic: **equal-weight mean net bp** (one trade, one vote), per symbol.

**Duration:** `close_dt − open_dt` from the TSV stamps; if 0, parsed text duration.

**Random-timing:** keep side, duration, lots. Randomize **entry** uniformly among Binance H1 bars whose timestamp falls in the **same ISO week as the real entry, in broker time** (Monday 00:00–Sunday 23:59 broker), and whose **broker weekday is Monday–Friday**. The book has **zero** weekend entries (profile, recorded). Exit = random entry + the same duration. Require an H1 close within **60 minutes** of the scheduled exit (H1 resolution); else redraw (max 100). If a trade’s valid pool is **< 10** bars, drop it from the whole test and report it.

The market on Binance is 24/7; ICM may close the weekend. Restricting the official pool to weekdays matches the book’s support. **Sensitivity (frozen, not a pick):** the same test with Saturday and Sunday H1 bars included in the pool.

**N = 2,000.** RNG `numpy.default_rng`, seed **213213** for BTC timing, **213214** for ETH timing.

**p-value (one-sided):** \(p = (1 + \#\{\bar r_{perm} \ge \bar r_{real}\}) / (N+1)\). “Beats random at p<0.05” means \(p < 0.05\).

**Random-side control:** keep real entry time, duration, size; replace side by a fair coin. Run entirely on **Binance H1 close at the real entry and exit hours**, real side vs random side, same RF costs. Seeds **213215** (BTC), **213216** (ETH). Does not replace the official timing test.

**Cluster robustness (secondary, frozen now):** shared U(0,1) inside each `(open_hour, side, symbol)` group (same-hour same-side stacks). Same N, seed+10. Cannot alone declare a pass or overturn a fail.
