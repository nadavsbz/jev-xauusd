## Official timing test

**Real bp (primary):** from the TSV **fill prices** (Open Price, Close Price; pips already identity-checked as 0.01-dollar gold pips), minus the RF cash and RF swap above, using the trade’s own timestamps for nights. This is the vendor’s realized move at **our** RF costs, not their broker’s commission line. Size is kept for EUR reconstructions but the official statistic is **equal-weight mean net bp** (one trade, one vote).

**Random-timing paths:** for each real gold trade in-universe, keep **side, duration, and lots**. Duration = `close_dt − open_dt` from the TSV stamps; if that is 0 (sub-minute, stamps truncated), use the parsed text duration (seconds). Randomize **entry** uniformly among Dukascopy M1 mid bars whose timestamp falls in the **same ISO week as the real entry, in broker time** (Monday 00:00–Sunday 23:59 broker). Exit = random entry + the same duration. Require a mid bar within **2 minutes** of the scheduled exit; otherwise redraw that trade (max 100 draws). If the valid entry pool for a trade is **< 10** bars, drop the trade from the whole test and report it.

**N = 2,000** permutations (≥ 1,000). RNG seed **212212** (numpy default_rng). For each perm, the statistic is the equal-weight mean net bp of the trades that found a valid random entry (should be all in-universe trades).

**p-value (one-sided, timing skill):** \(p = (1 + \#\{\bar r_{perm} \ge \bar r_{real}\}) / (N+1)\). Percentile = fraction of perms strictly below the real mean, × 100. “Beats random at p<0.05” means \(p < 0.05\).

**Random-side control (second test, not a substitute pass):** keep **real** entry time, duration, and size; replace side by an independent fair coin, seed **212213**, N=2,000, same costs and mid (for the control, **both** real-side and random-side P&L at the real times are computed on **the same price source** — TSV fills for the real-side mean, but a fair side-control must use the **same** mid path: therefore this control is run entirely on **Dukascopy M1 mid at the real entry and exit minutes**, real side vs random side. Report mean mid+RF-cost bp, p-value as above. This answers “is the **direction** skilled at the actual times?” It does **not** replace the official timing test.

**Cluster robustness (secondary, frozen now, not a pick):** 637 trades share a same-minute same-side open with at least one other (profile). Official test still randomizes **each trade independently**, as the brief says. Secondary: treat each `(open_minute, side)` group as one unit; shift the group’s base entry, keep within-group relative offsets and durations; same N and seed+1. Reported, cannot change a fail, and cannot alone declare a pass.

**Sensitivity (frozen, not a pick):** repeat the official timing test excluding trades with duration **< 2 minutes**, because M1 cannot see inside a 1-minute bar. Cannot change the official verdict’s *definition*; may be cited as a caveat if it disagrees.

## If and only if the gate passes: inference

Train **2018-01-01–2023-12-31**, holdout **2024-01-01** through last mid bar. Costs as above. Double-touch (SL and TP both reachable in the same bar) = **loss**. Gates g1–g5 (g5 = official BD crash_gate). Sharpe calendar × √365.25. 10% train-vol and exact 25% train-DD sizes. Corr to C1+I2, book lift.

**Candidate templates, frozen before inference P&L, taken from the profile’s timing shape and from published gold-session literature, not from a search after P&L:**

1. **NY-open scalp, short-or-long with prior-bar sign:** in a pre-registered 15:00–18:00 broker window (NY morning, NY+7), one trade: direction = sign of the previous M15 (or M1-60) close-to-close, time stop at the real median duration (~30 min) or a 1.5×ATR(M15,14) stop, whichever first; no grid.
2. **Asia 02:00–04:00 broker** (the other profile peak), same sign-following or fade (two **separate** pre-registered signs: follow vs fade), same stops.
3. **Split-lot average-in of at most 3 legs, 0.01 lot step, same direction, flattened together** — only as a **third** template, because the book is clearly clustered; this is a structural description, not a tuned grid.

No template gets a parameter search (no hour scan, no ATR multiple scan). If none of these three, run as specified, has holdout Sharpe ≥ 0.8 and passes g5, inference is “not recovered.” Report all three honestly. **Do not** start inference if the gate failed.
