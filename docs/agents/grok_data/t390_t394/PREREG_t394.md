## הגדרות
- פוזיציה = position_id: ‏t_open, צד, lots (volume הכניסה), ‏t_close = יציאה אחרונה, ‏PnL = Σ(profit+swap+commission) של כל ה-deals שלה. ‏MTM = Σprofit; עלויות = swap+commission.
- סל = (חשבון, magic, צד) עם חפיפת אינטרוולים (כמו t391_an). רמה = סדר הכניסה בסל. כל ה-magics (כל EA grid); כניסות magic=0 (ידני) נספרות בדלתא אבל לא נחסמות.
- **replay:** כרונולוגי על כל הצי. דלתא L(t)=Σ lots חתום של פוזיציות פתוחות **שלא נחסמו**. לכניסה ברמה ≥2 בסל שלא נחסם: ‏PS=|L+p|·100·12 + |p|·100·0.5 ‏(USC). אם PS>0.08·E0(d) → נחסמת, וכל הרמות המאוחרות של אותו סל = DESCENDANT_BLOCKED. E0 לא מתעדכן לפי ה-counterfactual (ASSUMED, שמרני כלפי מטה בערך).
- **counterfactual P&L:** פוזיציה חסומה → PnL=0 (חיסכון = −PnL שלה). פוזיציות שלא נחסמו → PnL בפועל (נסגרו בזמן הסגירה בפועל ≤ ההגנה; כלל GPT 4). הסתייגות ASSUMED: בלי tick replay אי אפשר לדעת אם הסל הקטן היה מגיע ל-TP אחר.
- **NetSaving** = −Σ PnL(חסומות). רווח שנזנח = Σ PnL חיובי נטו של חסומות. **לחץ:** רווחים שנזנחו (PnL>0) ×2; חיסכון עלויות (−swap−commission של חסומות) ÷2; לכל פוזיציה ששרדה בסל שנחסם: עלות נוספת ½ ספרד = 0.11$/oz (½·0.22 חציון ישיר t391) → 0.11·100·lots USC.
- **הפסד אירוע:** PnL בפועל של הפוזיציות של החשבון שהיו פתוחות ב-start ונסגרו ב-[start−5s, start+300s]. ‏ref = real_loss_pct·bal_before/100 (t376). משוחזר אם |ours−ref| ≤ 1%·|ref|.
