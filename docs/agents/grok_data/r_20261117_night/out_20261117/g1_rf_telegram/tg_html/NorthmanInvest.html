Hello everyone,

We would like to draw your attention to discrepancies in the RoboForex return statistics.

The returns displayed by RoboForex do not reflect the actual performance. This is because open trades – especially those held overnight or for extended periods – are included as losses in the RoboForex statistics.

You can use the profit amount in EUR shown in the RoboForex statistics as a reference value (it is displayed next to the percentage profit figure).

Example: Even if the percentage return is shown in red (negative), the profit displayed next to it in EUR may still indicate a real gain. In such cases, the trading system has in fact generated a profit and operated successfully.

Therefore, please do not be misled solely by the percentage return displayed in RoboForex, but rather focus on the profit shown in EUR.

Your Northman Invest Trading Team
