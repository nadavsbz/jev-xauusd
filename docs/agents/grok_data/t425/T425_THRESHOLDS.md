## Rules (fixed before applying to live)
- **DD:** WARN = 0.75 × hist max equity DD. STOP-AND-CONSULT = min(hist max, 25% hard cap); for BD = the 15% account equity protection. Measured as peak-to-trough on live equity, from the engine's start/reset.
- **Leverage/gross:** if hist max ≤ cap: WARN when live > 1.05 × hist max, STOP when live > cap. If the tester itself exceeded the cap (known post-entry drift; C1-A4 and I2-candidate), the naive rule is inconsistent (WARN > STOP). In that case WARN = any value > cap and STOP = min(1.05 × hist max, PREREG validity tolerance if one exists). This deviates from the brief, and the reason is stated here.
- **Monthly:** WARN when a live calendar month < P5. STOP when 2 consecutive months < P5, or 1 month < the historical minimum month.
- Percentiles: numpy linear interpolation over all complete calendar months.
