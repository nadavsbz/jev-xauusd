## 2. How 5%/month accounts usually fail the filter (OBSERVED / VERIFIED)

- **Grid / martingale / averaging:** AUDCAD–NZDCAD–AUDNZD clusters, equity DD ≫ balance DD, 85–98% WR with avg loss ≫ avg win, reviewer text saying "grid". Examples: Seagull, FXStabilizer, Beetle, AGI, RAZOR EA (review: "Fair grid system"), Harmonizer (author: "uses grid"), MSC Gold ("sophisticated grid"), NoPain/UpFuji/UpEverest, TwoHundredPercentAnnually, Sferica, Stable Return Portfolio, oilXM_BasicGrid (name).
- **Deposit-distorted Myfxbook "Monthly":** Gain ≫ Abs. Gain. **Trading Pro X1**: Gain +1,401%, Abs. Gain **+74%**, monthly printed 16.25% — not a real 16%/month (VERIFIED). **Wisdom EA (Axi Select)**: Gain +380%, Abs. Gain **+9.52%**, deposits $18.4k / withdrawals $19.2k, monthly printed 5.62% (VERIFIED). Sydney-heavy EURCHF + 84% WR + avg loss 3.7× avg win + Z = −8.16 — treat as grid-like.
- **Inflated MQL5 "Weeks":** VSA, HAN, FXKINGPIN, Signalium, FXtrading, RAZOR list 54–206 weeks but **Started** is 2026 (real age weeks to a few months). VERIFIED on the public "Started:" field.
- **Concentrated "80% of growth in N days"** MQL5 warning: Gold Trade Pro (12 of 1,133 days), Soma, Nobu Trap, Gold Minion, Precise Pair, Mon Scalper. The lifetime monthly rate is not a stable edge.
- **Already reverse-engineered and failed the frozen bar:** Gold Reaper (daily/intraday S/R breakout, 6%/month live, train gross-negative), Ferrari FX scalper, goldA (prior-day/Donchian breakout), goldfade. Do not retest the same family.

## 4. What this implies for a high-return test (OBSERVED)

Live 5%/month, ≤25% DD, non-grid, ≥12 months, and a public trade list **does not currently exist** on the public surfaces above, with one near-miss (JustLookClub: return and DD match, history incomplete, age possibly short) and one honest long-track futures book (ares: 2.5%/month). The gold-breakout EAs that do print 4–6%/month belong to a family this program already failed to reproduce on 2018–2023 (edge, not costs).

The only published **selective** breakout family we have **not** tested, with a large cited per-trade edge and a cost that clears the screen, is **Crabel NR7 / inside-day** (narrow-range or inside-day, then a next-day stop breakout, flatten the same session). That is a different rule from goldA's "break every prior-day / Donchian range." It is what the cost-screen and backtest in this round actually run. It is a **literature proxy**, not a clone of JustLookClub or Gold Trade Pro. Tag: ASSUMED as a research next step, not as a decode of a live book.
