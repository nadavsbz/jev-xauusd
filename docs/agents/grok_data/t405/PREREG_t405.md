5. **בלי grid/stacking/martingale:** ‏F2 — מקסימום פוזיציה פתוחה אחת. ‏F1/F3 — פוזיציה **נטו** אחת לסמל (אין לונג ושורט במקביל); הגדלות רק מ-rebalance של vol-target (VERIFIED בקוד: "No grid, no martingale, no averaging down"); ‏gross ≤ MaxGross 3.0 בכל רגע.
